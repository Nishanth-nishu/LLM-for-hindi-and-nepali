## 4. Interpretation

The corpus acquisition phase has been designed around a 500M-token target.

The exact token count cannot be finalized from file size or character count alone because tokenization depends on the selected vocabulary and tokenizer model.

Therefore the final report must replace the provisional figures with measured tokenizer counts.
